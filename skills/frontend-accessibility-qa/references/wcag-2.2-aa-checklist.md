# WCAG 2.2 A/AA Checklist

This file is a working checklist, not a copy of the normative W3C specification.

For exact wording, definitions, exceptions, and conformance requirements use:

https://www.w3.org/TR/WCAG22/

WCAG 2.2 is the hard baseline used by this skill when A/AA conformance is in scope.

## Important 2.2 migration note

WCAG 2.2 removed 4.1.1 Parsing as a success criterion. Do not report it as a WCAG 2.2 conformance failure.

## Contrast baseline

For the exact criterion and exceptions use the normative source.

Operational defaults for 1.4.3:

- normal text: 4.5:1 minimum;
- qualifying large text: 3:1 minimum.

Do not confuse 1.4.3 text contrast with 1.4.11 non-text contrast.

## Evidence

A checklist tick without evidence is not a conformance result.

Record affected routes/components/states, tools/manual method, and any environment limitation.
